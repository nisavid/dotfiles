# Cryptosacristy and Codiquarium name screen

Retain the selected project, operator, and command names, including `sacrypt`
and `cophax`. The small existing `sacrypt` project has no package in Arch's
official repositories and is disregarded under the operator's stated criterion.
The Cofax/KOFAX similarities are recorded below but do not hold up this naming
decision. This is a practical disposition, not a finding of legal clearance.

**Research date:** 2026-09-05

This screen covers the [selected naming family](CRYPTO_RELEASE_OPS_NAMING.md),
public software use, selected repository and package namespaces, and a bounded
US federal trademark search. It neither replaces the selected names nor
authorizes provisioning, registration, reservation, or implementation.

## US federal trademark screen

The following queries were submitted through the
[USPTO Trademark Search interface](https://tmsearch.uspto.gov/) on 2026-09-05.
The query expressions add no live-status or goods/services-class conditions;
the returned cards below include both live and dead records. `CM` searches
the combined mark field; the query grammar and broader-search guidance come from
the [USPTO's federal searching guide](https://www.uspto.gov/trademarks/search/federal-trademark-searching).

1. Selected words:

   ```text
   CM:(cryptosacristy OR cryptosacrist OR cryptosteward OR cryptostewards OR cryptopraxis OR codiquarium OR codophylax OR sacrypt OR cophax)
   ```

   The interface returned **No results found**.

2. Selected stems, including marks containing those strings:

   ```text
   CM:(/.*cryptosacri.*/ OR /.*cryptosteward.*/ OR /.*cryptopraxi.*/ OR /.*codiquar.*/ OR /.*codophyla.*/ OR /.*sacrypt.*/ OR /.*cophax.*/)
   ```

   The interface returned **No results found**.

3. Close command spellings/pronunciations:

   ```text
   CM:(cofax OR kofax OR cophax OR kophax)
   ```

   The interface returned **10 results**, all on one page. They were KOFAX or
   KOFAX-containing marks. Two KOFAX records were **LIVE / REGISTERED**:

   | Serial number | Owner shown | Goods/services shown in the result card |
   | --- | --- | --- |
   | 75777177 | Tungsten Automation Corporation | Class 009; computer software and hardware for document image processing. |
   | [77376644](https://tmsearch.uspto.gov/search/search-results/77376644) | Tungsten Automation Corporation | Classes 009 and 042; computer software and related hardware. |

   These are summaries of the result cards, not the complete goods/services
   identifications. The company's own
   [Kofax-to-Tungsten rebranding announcement](https://www.tungstenautomation.com/press-releases/2024/kofax-is-now-tungsten-automation)
   corroborates the software business. The rebrand does not make the KOFAX
   registrations disappear: the search still labels those two records live.

4. Spaced project associations and a nearby crypto command spelling:

   ```text
   CM:("crypto sacristy" OR "code aquarium" OR secrypt OR sacrypt)
   ```

   The interface returned **2 results**, both SECRYPT: serial 78073958 was
   **DEAD / ABANDONED**, and serial 75768090 was **DEAD / CANCELLED**. No result
   was shown for the other three alternatives. These dead federal records do
   not establish that SECRYPT is unused or free of other rights.

The USPTO guide explains why absence of an identical mark is insufficient:
similarity in sound, appearance, meaning, or commercial impression and the
relationship between goods/services matter. Sharing a software class alone
does not decide that relationship. This report therefore flags the KOFAX
resemblance without deciding the legal outcome for release-operations tooling.

## Limits and next decision

This is a preliminary practical screen, not comprehensive trademark clearance
or legal advice. It does not exhaust US state or common-law rights, foreign
registers, spelling variants, package ecosystems, domains, or social handles.
Negative searches are dated observations, not guarantees. Public search
engines can miss unindexed projects, and an available package spelling can
still be a poor public name.

**Release writ** and **admission verdict** remain ordinary domain vocabulary
for the existing records/results, not separately cleared product brands.
Codiquarium worker/documentation names and the hypothetical Writ Bureau remain
outside this screen.

The command-name question is settled for this increment: retain `sacrypt` and
`cophax` with the institution/operator pairing. Repository provisioning and
package publication remain separate steps; protocol identifiers, data types,
and project scope are unchanged.
